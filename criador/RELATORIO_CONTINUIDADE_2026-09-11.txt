OBJETIVO GERAL DO PROJETO
-------------------------
Fazer o SEG Vendas operar profissionalmente e integrar-se ao Dataplace Symphony
Cloud para receber produtos, descrições, preços, EAN, estoque por filial,
clientes e manuais, preservando a operação independente de cada loja.

O desenho decidido é local-first:

Dataplace Cloud -> integrador/hub no Azure -> servidores locais das lojas

Cada loja continua com:
- SEG Vendas local;
- dados locais;
- Gertec local na porta TCP 6500;
- funcionamento quando internet, Azure ou Dataplace estiverem indisponíveis;
- fila para sincronizar quando a conexão retornar.

O Azure será usado futuramente para sincronização, auditoria, compartilhamento
controlado entre lojas e proteção adicional dos dados. Não será necessário para
cada leitura do Gertec.

FONTES OFICIAIS DEFINIDAS
-------------------------
- Produtos: Dataplace.
- Descrições: Dataplace.
- Preços: Dataplace.
- EAN/códigos de barras: Dataplace.
- Estoque por filial: Dataplace.
- Clientes: Dataplace.
- Manuais de produtos: Dataplace, respeitando autorização de distribuição.
- Orçamentos e pedidos: originados na loja e enviados para a central.
- Configuração de rede e Gertec: exclusiva de cada loja.
- Funcionários: regras de autoridade, desligamento e permissões ainda precisam
  ser confirmadas antes da automação.

REGRAS IMPORTANTES
------------------
- O Gertec permanece somente na rede local de cada loja.
- O SEG não deve sobrescrever preço ou estoque oficial do Dataplace.
- Nunca substituir dados locais válidos por arquivos vazios, incompletos,
  inválidos ou mais antigos.
- Sincronização não substitui backup.
- Git não guarda os dados ignorados e não substitui backup.
- Dados de laboratório e produção devem permanecer separados.
- Não incluir dados reais, credenciais ou backups no GitHub.
- Não excluir arquivos sem confirmação explícita.
