Guia de uso — SEG Vendas 5.3

Novo fluxo: primeiro o login; depois o menu “Onde você quer ir hoje?”.

Entrar no aplicativo

Use o código do funcionário ou o nome de usuário. Para contas com código, a senha inicial segue o padrão SEG@CÓDIGO. Exemplo: código 25 e senha SEG@25.

Trocar a senha

Depois de entrar, clique no botão de chave no cabeçalho, informe a senha atual e crie uma nova senha.

Perfil Cliente

O cliente vê somente Catálogo e Manuais. O fórum, os orçamentos, a pesquisa de clientes, o histórico e os ajustes ficam bloqueados.

Criar orçamento

  1. No menu principal, abra Novo Orçamento.
  2. Selecione ou pesquise o cliente.
  3. Pesquise produtos por código ou descrição.
  4. Confirme quantidade, desconto, frete e pagamento.
  5. Salve e envie como foto, PDF ou texto.

Fotos dos produtos

Somente coordenadores e administradores podem alterar. As imagens ficam em data\fotos_produtos.

Manuais e suporte

Na Central Técnica, pesquise primeiro no SEG Ajuda. Clientes recebem somente manuais marcados como públicos.

Acesso externo: o computador que executa o servidor precisa permanecer ligado. Para acesso fora da loja, configure IP e porta pelo atalho próprio e use um túnel HTTPS protegido, sem abrir diretamente o servidor HTTP na internet.
